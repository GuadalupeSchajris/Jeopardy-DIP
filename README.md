# 🎮 **Jeopardy Game** 🎮

## 📖 Descripción
¡Bienvenid@ al **Jeopardy Game**! Este proyecto es una versión interactiva del famoso juego **Jeopardy** desarrollado con **React**. Los jugadores podrán competir respondiendo preguntas y acumulando puntos. Con una interfaz simple y atractiva, puedes jugar con amigos o en solitario para probar tus conocimientos. ¡Que empiece el reto!

🎯 **Objetivo**: Crear una experiencia de juego divertida y educativa con una interfaz amigable, donde los participantes puedan interactuar fácilmente y acumular puntos por sus respuestas correctas.

## ✨ Características
- **Juego interactivo**: Los participantes pueden seleccionar categorías y responder a preguntas de diferentes temas.
- **Gestión de puntuaciones**: Los puntos se acumulan automáticamente por cada respuesta correcta pero se introducen manualmente . Puedes visualizar las puntuaciones de todos los jugadores en tiempo real.
- **Selección de participantes**: Puedes seleccionar manualmente al participante que responde y asignarle puntos según su respuesta.
- **Responsive**: ¡Funciona perfectamente en móviles, tablets y escritorios!
- **Diseño intuitivo**: Fácil de jugar y entender para todos los públicos.

## ⚙️ Tecnologías Utilizadas
- **React**: Para crear la interfaz dinámica y reactividad.
- **CSS**: Para estilizar y hacer que el juego se vea atractivo.
- **JavaScript**: Para la lógica del juego y la interacción con el DOM.
- **Node.js**: Para la ejecución del servidor en desarrollo.
